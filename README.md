# Stress and Productivity tracker

## Short description of the Api
This Api is used to handle the requests from prodtrackerfrontend (https://github.com/Joelljunggren/prodtrackerfrontend).

It uses and sqlite database where it holds all created entries so that they can be used in the applications front-end.

It also uses the Nuget package Swagger for a clear overview of all the currently available Api-calls. It can also be used to test if the calls are doing what is expected of them.

## Starting the project
Shouldnt be any major issues here. Just clone and run it, the swagger window will open in your selected browser.
